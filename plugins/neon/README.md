# Neon

Официальный сервер Neon: проекты и ветки базы, SQL-запросы, миграции.

## MCP-серверы

- `neon` → https://mcp.neon.tech/mcp

## Установка

```sh
codex plugin add neon --marketplace kalitka
```

## Авторизация

OAuth в браузере: `codex mcp login neon` — сервер поддерживает Dynamic Client Registration, ни client_id, ни переменных окружения не нужно.

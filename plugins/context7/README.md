# Context7

Подтягивает свежую документацию и примеры кода любой библиотеки прямо в контекст агента вместо того, что модель помнит по обучающей выборке. Тулы: resolve-library-id, query-docs. Работает без ключа; ключ нужен только для повышенных лимитов.

## MCP-серверы

- `context7` → https://mcp.context7.com/mcp

## Установка

```sh
codex plugin add context7 --marketplace kalitka
```

## Авторизация

Авторизация не нужна вообще — сервер отвечает анонимно.

## Заметки

Проверено 20.08.2026: `initialize` отдаёт 200 анонимно, `tools/list` — `resolve-library-id`, `query-docs`.

У сервера есть и OAuth с DCR (`https://context7.com/api/oauth/register`) — нужен, только если упрётесь в лимиты бесплатного анонимного доступа.

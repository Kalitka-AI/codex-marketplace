# Kalitka AI

Навыки Kalitka AI для Codex.

| Навык | Что делает |
|---|---|
| Nano Banana | Рисует и правит картинки моделью Nano Banana (Google), когда нужна именно она, а не встроенный генератор Codex. Модель должна входить в тариф. |

## Установка

Приложение Kalitka AI ставит плагин само. Руками:

```sh
codex plugin add kalitka-ai --marketplace kalitka
```

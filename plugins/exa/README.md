# Exa Search

Семантический поиск по вебу и загрузка найденных страниц через Exa. Тулы: web_search_exa, web_fetch_exa. Дополняет встроенный web_search, когда нужен именно поиск по смыслу.

## Установка

```sh
codex plugin add exa --marketplace kalitka
```

## Авторизация

Авторизация не нужна вообще — сервер отвечает анонимно.

# Exa Search

Семантический поиск по вебу и загрузка найденных страниц через Exa. Тулы: web_search_exa, web_fetch_exa. Дополняет встроенный web_search, когда нужен именно поиск по смыслу.

## MCP-серверы

- `exa` → https://mcp.exa.ai/mcp

## Установка

```sh
codex plugin add exa --marketplace kalitka
```

## Авторизация

Авторизация не нужна вообще — сервер отвечает анонимно.

## Заметки

Проверено 20.08.2026: `initialize` — 200 анонимно, `tools/list` — `web_search_exa`, `web_fetch_exa`.

**Не проверено:** лимиты анонимного доступа и надолго ли он бесплатный. У сервера есть discovery (`auth.exa.ai`, скоуп `mcp:tools`) — если упрётесь в лимиты, понадобится ключ.
